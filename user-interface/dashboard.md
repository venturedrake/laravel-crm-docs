# Dashboard

[[toc]]

## Overview

The dashboard is the landing page of the CRM, accessible at `/crm`. It provides a high-level summary of your CRM data with quick-glance statistics.

## Summary Cards

The dashboard displays summary cards for each enabled module:

| Card | Description |
|---|---|
| **Leads** | Total number of leads (shown when leads are enabled) |
| **Deals** | Total number of deals (shown when deals are enabled) |
| **People** | Total number of people contacts |
| **Organisations** | Total number of organisations |

Each card shows the total count and a label. The cards are displayed in a responsive grid layout.

## Feature Visibility

Summary cards respect the feature toggle settings. For example, if leads are disabled in [Settings](/user-interface/settings), the leads card will not appear on the dashboard. Similarly, the deals card is hidden when deals are disabled.
