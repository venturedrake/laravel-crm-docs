# Contacts

[[toc]]

## People

The People section provides a directory of individual contacts. Access it from the sidebar navigation.

### List View

People are displayed in a paginated table showing name, email, phone, organisation, and owner. Use search to find contacts by name. Filter by owner or labels.

### Creating a Person

Click **Create** to add a new person. The form includes:

- **First Name / Last Name** — Contact name fields.
- **Title** — Optional title (Mr, Mrs, Dr, etc.).
- **Organisation** — Link to an existing organisation using autocomplete.
- **Email Addresses** — Add multiple email addresses with type (work, home, other). The first is marked as primary.
- **Phone Numbers** — Add multiple phone numbers with type selection.
- **Addresses** — Add one or more structured addresses.
- **Labels** — Assign colour-coded labels.
- **Custom Fields** — Any configured custom fields.

### Person Detail Page

The detail page shows all contact information plus related records — associated deals, leads, organisation, and an activity timeline for tracking all interactions with this contact.

## Organisations

The Organisations section manages company and business records.

### List View

Organisations are listed with name, address, and owner columns. Search and filter capabilities work the same as other list views.

### Creating an Organisation

The organisation form includes:

- **Name** — Organisation/company name.
- **Email Addresses** — Company email addresses with type selection.
- **Phone Numbers** — Company phone numbers with type selection.
- **Addresses** — One or more business addresses.
- **Labels** — Colour-coded labels.
- **Custom Fields** — Any configured custom fields.

### Organisation Detail Page

Shows organisation details plus linked people, deals, leads, and the activity timeline.

## Clients

Clients are a wrapper entity that links a person and/or organisation together as a unified customer record. This is useful when you need to track a specific person at a specific organisation as a single client entity.

### Creating a Client

You can create clients:

- Directly from the Clients section using the create form.
- From a person or organisation detail page.

The form lets you select an existing person and/or organisation, or create them inline.
