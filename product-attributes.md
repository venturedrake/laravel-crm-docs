# Product Attributes

[[toc]]

## Overview

The Product Attributes page was removed in 2.5.0. It was an unfinished v1 stub with no table and no views, so every route errored with `Table 'product_attributes' doesn't exist`.

- **For sizes, colours and other versions of a product**, use [Product Variations](/product-variations). Each variation has its own SKU, barcode, price and active flag, and can be picked on line items.
- **For product details such as material, brand or warranty**, attach [custom fields](/custom-fields) to Products.

To upgrade an install that still links to the old page, see [Upgrading to 2.5.0 → Product Attributes removed](/upgrading#product-attributes-removed).
